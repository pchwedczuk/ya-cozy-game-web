# YA Cozy Game — wersja przeglądarkowa

Zbudowana gra (Godot 4.6, eksport Web, jednowątkowy) publikowana przez GitHub Pages.
Zagraj: https://pchwedczuk.github.io/ya-cozy-game-web/

To repozytorium zawiera wyłącznie pliki wynikowe eksportu — kod źródłowy jest w prywatnym repozytorium projektu.
Aktualizacja: `powershell -File Tools/export_web.ps1` w projekcie źródłowym.
